# Ровер-ралли

Гонка для вечеринки: на общем экране ведущий создаёт комнату и запускает заезд, а участники нажимают «ГАЗ» на телефонах. Трасса, большой QR и управление находятся на одной странице. У каждого участника свой ровер. Чем быстрее игрок нажимает, тем быстрее он едет.

Ровер получает номер, случайный цвет из двенадцати и один из четырёх маршрутов. Цвет не определяет дорожку. Номер отличает роверы одного цвета; цвет и маршрут сохраняются при повторном входе. Представляться не нужно.

Трасса состоит из четырёх извилистых дорожек из брусчатки и грунта с пересечениями и общим финишем. У всех маршрутов одинаковая длина. Растения и роверы перекрывают друг друга в зависимости от положения на поле.

Ведущий выбирает дистанцию 150, 300 или 500 метров. После начала заезда новые игроки ждут следующего старта. Гонка заканчивается на финише или через три минуты; тогда побеждает игрок, который проехал дальше. При равном результате — ничья.

Первый финиш сразу останавливает всех роверов. У победителя открывается крышка, крупный букет невесты вылетает к центру, а фон трассы темнеет. Общий экран показывает номер и цвет победителя, а на его телефоне вместо кнопки появляется букет. При завершении по времени букет на трассе не появляется.

Комната и результаты сохраняются на сервере. После перезагрузки страницы игрок возвращается к своему роверу, а ведущий сохраняет управление в том же браузере.

При первом обновлении с командной версии существующие комнаты возвращаются в ожидание старта. Игроки получают личные номера, доступ ведущего и вход участников сохраняются.

## Запуск локально

Нужен Node.js 24.

```bash
npm --prefix app install
npm --prefix app run dev
```

Во втором терминале запусти сервер игры:

```bash
npm --prefix app run server:dev
```

Открыть адрес из вывода `dev` на общем экране и создать комнату. Игроки сканируют большой QR, переходят по ссылке или вводят код комнаты. Ссылка сразу открывает кнопку «ГАЗ» и номер своего ровера. Управление заездом доступно в браузере, где создана комната; старые ссылки на экран ведущего и трансляцию открывают ту же страницу.

Для запуска собранного приложения:

```bash
npm --prefix app run build
npm --prefix app start
```

Один сервер раздаёт приложение и синхронизирует игру между устройствами. Для игры через интернет разверни его на виртуалке: [инструкция](docs/deploy-single-vm.md). Для демо рядом с другим сайтом скрипт `scripts/update-vm.sh` открывает игру по IP на отдельном порту. Через существующий прокси можно подключить поддомен или разместить игру по пути `/rover/` на одном домене с другим сайтом.
