# Ровер-ралли

Командная гонка для вечеринки: ведущий создаёт комнату, общий экран показывает трассу, а участники нажимают «ГАЗ» на телефонах. Чем быстрее команда нажимает, тем быстрее едет её ровер.

В игре четыре команды: красная, зелёная, синяя и жёлтая. Игроки попадают в команды случайно, с учётом их размера. Несколько человек могут управлять одним ровером.

Трасса состоит из четырёх извилистых дорожек из брусчатки и грунта с пересечениями и общим финишем. У всех маршрутов одинаковая длина. Растения и роверы перекрывают друг друга в зависимости от положения на поле.

Разница в составе команд — не больше одного игрока. Скорость зависит от среднего темпа нажатий всей команды: численное преимущество не помогает. Ведущий выбирает дистанцию 150, 300 или 500 метров. После начала заезда новые игроки ждут следующего старта. Гонка заканчивается на финише или через три минуты; тогда побеждает команда, которая проехала дальше. При равном результате — ничья.

Комната и результаты сохраняются на сервере. После перезагрузки страницы игрок возвращается в свою команду, а ведущий сохраняет управление в том же браузере.

## Запуск локально

Нужен Node.js 24.

```bash
npm --prefix app install
npm --prefix app run dev
```

Во втором терминале запусти сервер игры:

```bash
npm --prefix app run server:dev
```

Открой адрес из вывода `dev`. Ведущий создаёт комнату и открывает экран трансляции на телевизоре. Игроки сканируют большой QR, переходят по ссылке или вводят код комнаты. Представляться не нужно: ссылка сразу открывает кнопку «ГАЗ» и назначенную команду.

Для запуска собранного приложения:

```bash
npm --prefix app run build
npm --prefix app start
```

Один сервер раздаёт приложение и синхронизирует игру между устройствами. Для игры через интернет разверни его на виртуалке: [инструкция](docs/deploy-single-vm.md).
